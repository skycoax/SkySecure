# Public Suffix List — curated subset
#
# Full PSL is ~230 KB and changes weekly; shipping all of it in the APK is not
# worth the size for our threat model. This subset covers: the gTLDs and ccTLDs
# that actually appear in UZ-region phishing, the multi-label suffixes we must
# get right (*.uz in particular), and the free-hosting / dynamic-DNS suffixes
# where each subdomain is a separate trust boundary and must therefore be
# treated as its own registrable domain.
#
# Syntax is the real PSL syntax: plain rule, `*.` wildcard, `!` exception.
# Unknown TLDs fall back to "last label is the suffix", which is the correct
# conservative default.
#
# This file is shipped in the signed update feed (feed key: psl_subset) so it
# can be corrected without an app release.
